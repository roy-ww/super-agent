### 项目概述

这是一个名为 **“Gemini AI 对话应用”** 的项目。其核心功能是提供一个Web聊天界面，让用户可以与多种不同的人工智能（AI）模型进行对话。

### 核心功能

1.  **多模型支持**：项目最核心的特性是同时集成了两种AI服务：
    *   **Google Gemini**：一个强大的云端AI模型。
    *   **Ollama**：一个支持在用户本地计算机上运行多种开源AI模型（如Llama2, CodeLlama等）的框架。
2.  **模型切换**：用户可以在界面上方便地一键切换，选择使用云端的Gemini模型还是本地的Ollama模型。
3.  **实时状态检测**：应用能够自动检测并显示每种模型（Gemini和Ollama）是否可用，提供了良好的用户体验。
4.  **对话管理**：支持创建和管理多个对话，并且对话历史会根据所使用的AI模型进行分类。
5.  **现代化界面**：采用响应式设计，适配桌面和移动设备，并支持深色/浅色主题切换。

### 技术架构

该项目基于目前主流的前端技术栈构建：

*   **框架**：**Next.js 14** (使用最新的 App Router 架构)。这是一个基于React的服务端渲染框架，性能优秀且功能强大。
*   **语言**：**TypeScript**。为项目提供了静态类型检查，增强了代码的健壮性和可维护性。
*   **样式**：**Tailwind CSS**。一个实用工具优先的CSS框架，用于快速构建自定义界面。
*   **后端API**：利用 **Next.js API Routes** 实现后端功能。这意味着前端和后端代码都在同一个项目中，简化了开发和部署。
    *   `api/chat/route.ts`：处理所有聊天消息的核心API，它会根据用户的选择，将请求转发给Gemini或Ollama。
    *   `api/models/route.ts`：一个辅助API，用于检查后端配置的AI模型当前是否在线且可用。

### 工程结构

项目的目录结构经过了精心优化，代码组织得非常清晰：

*   `app/`: Next.js应用的核心目录。
    *   `components/`: 存放可重用的React组件，如 `ChatMessage.tsx` (聊天消息) 和 `ModelSelector.tsx` (模型选择器)。
    *   `hooks/`: 存放自定义的React Hooks，如 `useModels.ts` (管理模型状态) 和 `useTheme.ts` (管理主题)。
    *   `api/`: 存放所有后端API路由。
    *   `lib/`: 存放核心的库代码，例如 `ai-clients.ts`，其中封装了与Gemini和Ollama服务交互的逻辑。
    *   `types/`, `utils/`, `constants/`, `styles/`: 分别用于存放TypeScript类��定义、工具函数、全局常量和样式文件。
*   `docs/`: 包含了非常详尽的中文文档，包括产品需求、项目总结和架构优化总结，这对于理解项目背景和后续维护非常有帮助。
*   `public/`: 存放静态资源文件（如图片）。
*   根目录下的配置文件：如 `package.json` (项目依赖)、`next.config.js` (Next.js配置)、`tailwind.config.js` (Tailwind配置) 等。

### 总结

总的来说，这是一个功能完整、技术栈现代、结构清晰且文档完备的AI聊天应用。它不仅实现了核心的对话功能，还通过支持本地Ollama模型，巧妙地解决了用户对于数据隐私和API成本的顾虑。代码经过了良好的模块化拆分，易于理解、维护和扩展。
