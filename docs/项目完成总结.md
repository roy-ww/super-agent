## 🚀 如何运行项目

### 前置条件
选择至少一种AI模型：

#### 选项A：Google Gemini（云端）
1. 访问 [Google AI Studio](https://makersuite.google.com/app/apikey)
2. 创建API密钥
3. 配置到 `.env.local` 文件

#### 选项B：Ollama（本地）
```bash
# 安装 Ollama
brew install ollama  # macOS
# 或从官网下载: https://ollama.ai

# 启动服务
ollama serve

# 下载模型
ollama pull llama2        # 通用对话
ollama pull codellama     # 代码专用
ollama pull qwq           # 推理模型
```

### 启动应用

#### 方法一：快速启动（推荐）
```bash
./start.sh
```

#### 方法二：手动启动
```bash
npm install
npm run dev
```

## 🎯 使用建议

### 推荐的模型选择策略

#### 🤖 选择Gemini的场景
- 需要最高质量的回答
- 处理复杂的推理任务
- 多语言翻译
- 创意写作

#### 🦙 选择Ollama的场景
- 注重隐私，需要本地处理
- 离线环境使用
- 控制API成本
- 代码相关任务（codellama）
- 快速响应需求

### 部署建议
1. **开发环境**: 同时配置两种模型以便测试
2. **生产环境**: 根据用户需求选择合适的模型
3. **企业环境**: 推荐使用Ollama确保数据安全
